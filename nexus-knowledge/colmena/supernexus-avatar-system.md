# supernexus-avatar-system

Sistema de avatares SuperNEXUS: NO es una imagen simple. Tiene: 9 ninja avatars (Mm array con id/name/file), AvatarRenderer con scanner rings + emociones (idle/listening/thinking/speaking), AvatarWindow con selector de temas (Director/Ghost), modo ASCII + imagen, ventana draggable, persistencia en localStorage (nexus-avatar-ninja-id). El golden bundle tiene todo el código. El source está desincronizado. SIEMPRE restaurar desde golden, no inventar.
