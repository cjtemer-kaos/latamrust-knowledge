# supernexus-error-prevention

LECCIONES APRENDIDAS - Errores a no repetir:
1. NUNCA reescribir archivos desde cero → el golden bundle tiene todo
2. SIEMPRE analizar con DevTools ANTES de modificar código
3. Avatar NO es imagen simple → sistema complejo con 9 ninjas, themes, scanner rings
4. Archivos estáticos (ninjas/, kaos.png) van en ui/public/ para que vite los copie
5. Electron pantalla negra → cerrar TODAS las instancias (una es Hermes Agent)
6. Browser puede funcionar diferente a Electron → verificar en ambos
7. Source files pueden estar desactualizados vs golden bundle → comparar siempre
8. No agregar features no solicitadas → hacer solo lo que el usuario pide
9. Si el usuario dice "no me inventes cosas" → usar lo que ya existe
10. Guardar aprendizajes en cerebro periódicamente, no solo al final
