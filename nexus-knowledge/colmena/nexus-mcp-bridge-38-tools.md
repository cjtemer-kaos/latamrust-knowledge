# nexus-mcp-bridge-38-tools

MCP bridge connects SuperNEXUS to external systems via 38 tools. Categories: PC2 REMOTE: execute_on_pc2, list_nodes, get_system_info, execute_remote_task. NEXUSHIVE COMM: send_message, read_messages, memory_set, memory_get. BRAIN: brain_remember, brain_recall, brain_stats. MEMORY/FTS5: add_observation, search_observations, get_observation, add_task_finding, list_findings, memory_stats. SKILLS: list_skills, load_skill, load_skill_section. SYSTEM: nexus_status, system_resources, optimize_prompt, select_model, token_report. BLAST: add_finding, add_decision, read_cloud, check_permissions. ROUTING: router_select, router_stats. SELF-LEARNING: self_learning_status. HIERARCHICAL MEMORY: memory_hierarchical_stats, memory_hierarchical_store, memory_hierarchical_search. HYBRID RETRIEVAL: retrieval_search. ANTI-GRAVITY: send_task_to_antigravity.
