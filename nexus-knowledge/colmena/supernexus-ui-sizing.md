# supernexus-ui-sizing

SuperNEXUS v2 - Tamaño UI para 1080p: font-size base 18px en globals.css (no 16px default). Sidebar 260px, right panel 280px. Input bar: padding px-4 py-3, font text-base, iconos 20px, send button p-2.5. Mensajes: text-base px-5 py-3.5. Quick prompts: text-sm px-4 py-2. Para distribución, considerar que otros usuarios pueden tener monitores más pequeños.
