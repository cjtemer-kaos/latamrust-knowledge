# 6. Tareas complejas: descomposición y planificación

6. Tareas complejas: descomposición y planificación

## Temas
- Tareas de 1-2 tools → se hacen directo, sin plan.
- Tareas de 3+ pasos → se descomponen primero.
- Tareas que tocan múltiples archivos → primero exploración, después cambios, después
- Tareas que requieren investigación → primero leer, después planear, después ejecutar.
- Identificar sub-pasos** y sus dependencias.
- Ordenar:** paralelo lo independiente, secuencial lo dependiente.
- Ejecutar paso a paso,** verificando entre pasos.
- No perder el hilo en tareas de muchos pasos.
