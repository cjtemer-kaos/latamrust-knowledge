# 4. Uso de herramientas (tool use)

Las herramientas son cómo el agente afecta el mundo. Sin tools, solo conversa.

## Temas
- Fase de exploración:** leo todos los archivos involucrados.
- Fase de edición:** hago todos los edits en un solo turno (paralelo).
- Fase de verificación:** corro tests/lint para confirmar que todo funciona.
- Compilar (`npm run build`, `cargo build`, `go build`)
- Testear (`pytest`, `npm test`, `cargo test`)
- Instalar dependencias (`pip install`, `npm install`)
- Navegar el sistema de archivos (aunque prefiero read/glob)
- Ver logs, estados, procesos
