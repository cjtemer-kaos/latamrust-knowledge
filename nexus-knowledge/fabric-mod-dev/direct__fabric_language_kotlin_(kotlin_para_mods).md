# Direct: Fabric Language Kotlin (Kotlin para mods)

Category: Fabric-mod-dev
Tags: direct-learned
Created: 2026-08-20T16:40:36.283722

---

Fabric Language Kotlin (FLK) es un mod librería (Modrinth ID 'fabric-language-kotlin', categoría library, loader fabric) que habilita el uso del lenguaje Kotlin en mods Fabric, proporcionando el runtime/stdlib de Kotlin. Compatible con 1.21.1 (y amplio rango de versiones, de 1.14 a 26.2). Para usar Kotlin en un mod Fabric se añade FLK como dependencia (dependencia de mod + artefacto Gradle) además de Loom.
