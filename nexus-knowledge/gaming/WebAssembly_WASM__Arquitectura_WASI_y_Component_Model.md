# WebAssembly (WASM) — Arquitectura, WASI y Component Model

WebAssembly (Wasm) es un formato binario portable como objetivo de compilacion para C/C++, Rust y Go. Se ejecuta en sandbox seguro con rendimiento near-native. WASI (WebAssembly System Interface) es la capa de interfaz de sistema para acceder a archivos, red, HTTP y relojes fuera del navegador, con modelo de seguridad basado en capacidades (capability-based security). WASI 0.2 (estable 2026) incluye interfaces filesystem, sockets, HTTP, clocks y random. WASI 0.3 anade async nativo con tipos stream<T> y future<T>. Component Model (WIT - Wasm Interface Type) permite componer modulos de distintos lenguajes en un mismo espacio de memoria con interfaces tipadas. Runtimes principales: Wasmtime (Bytecode Alliance), WasmEdge (CNCF), Wasmer, WAMR (IoT). Produccion: Cloudflare Workers, Fastly Compute, Fermyon Spin, Docker+Wasm, wasmCloud. Ventajas sobre contenedores: arranque en microsegundos (vs ms de microVM), footprint de MB (vs GB), seguridad por defecto.
