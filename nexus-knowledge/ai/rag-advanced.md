# rag-advanced

Advanced RAG: 1) Query expansion: multiple queries per user input. 2) HyDE: hypothetical document embedding. 3) Self-RAG: model decides when to retrieve. 4) CRAG: corrective retrieval. 5) Multi-hop reasoning: iterative retrieval. 6) Graph RAG: knowledge graph + vectors. 7) Contextual compression: reduce retrieved text. 8) Parent-child chunking.
