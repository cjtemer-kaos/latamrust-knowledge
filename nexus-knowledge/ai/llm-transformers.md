# llm-transformers

Transformers architecture: 1) Self-attention: each token attends to all others. 2) Multi-head attention: parallel attention layers. 3) Positional encoding: order matters. 4) Encoder-decoder: translation, summarization. 5) Decoder-only: GPT, text generation. 6) BERT: encoder-only, classification. 7) Training: next token prediction. 8) Inference: autoregressive generation.
