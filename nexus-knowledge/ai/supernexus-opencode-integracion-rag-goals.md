# supernexus-opencode-integracion-rag-goals

INTEGRACION OpenCode con Nexus: OpenCode (CLI/TUI) usa SuperNEXUS como brain base via provider nexus en http://127.0.0.1:9000/v1. OpenCode tiene 7 MCP servers: nexus-bridge (87 tools), chrome-devtools, playwright, context7, brave-search, github, agent-browser. OpenCode usa RAG de Nexus: rag_index/index_file/index_search via MCP tools rag_index y rag_search. DAG goals: dag_decompose descompone objetivo en grafo de tareas con dependencias (TaskNode con id,title,description,assignee,status). run_agent_loop ejecuta tareas autonomas iterativas TDAO. run_harness pipeline completo decompose-execute-synthesize-verify. OpenCode tambien usa brain_remember/brain_recall para memoria compartida. Provider auto: Director auto-selects best model. Providers disponibles: nexus/auto (Director), nexus/qwen-coder, nexus/deepseek-reason, nexus/nemotron, ollama (11 modelos locales), zen (modelos gratuitos cloud).
