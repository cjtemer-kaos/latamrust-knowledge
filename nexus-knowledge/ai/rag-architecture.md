# rag-architecture

RAG (Retrieval-Augmented Generation): 1) Index documents into vector DB. 2) User query → embed → search similar docs. 3) Retrieved docs + query → LLM. 4) Chunking strategies: fixed, semantic, recursive. 5) Embedding models: OpenAI ada, sentence-transformers. 6) Vector DBs: Pinecone, Weaviate, Chroma, FAISS. 7) Hybrid search: BM25 + vectors. 8) Re-ranking for relevance.
