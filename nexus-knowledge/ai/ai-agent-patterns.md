# ai-agent-patterns

AI agent patterns: 1) ReAct: Reason + Act loop. 2) Plan-and-Execute: plan first, then do. 3) Reflexion: learn from mistakes. 4) Tool Use: function calling. 5) Multi-agent: specialized agents collaborate. 6) Memory: short-term (context) + long-term (vector DB). 7) Planning: goal decomposition.
