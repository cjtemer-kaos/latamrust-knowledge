# llm-tokenization

Tokenization: 1) BPE (Byte Pair Encoding): GPT, Llama. 2) WordPiece: BERT. 3) SentencePiece: multilingual. 4) Token limits: 4K-128K tokens. 5) Context window: max tokens in prompt. 6) Truncation strategies: head, tail, middle. 7) Special tokens: [CLS], [SEP], [PAD]. 8) Token cost: ~$0.01-0.06/1K tokens.
