# pair-programming

Pair programming: 1) Driver: types code. 2) Navigator: reviews, thinks ahead. 3) Switch every 20-30 min. 4) Useful for: complex bugs, new features, onboarding. 5) Not useful for: simple tasks, deep focus work. 6) Remote: VS Code Live Share, Tuple. 7) Mob programming: 3+ people on one screen.
