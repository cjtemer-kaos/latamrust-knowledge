# Domain-Driven Design (DDD)

DDD: model complex domains with Ubiquitous Language (shared team vocabulary). Building blocks: Entity (identity), Value Object (immutable, equality by value), Aggregate (consistency boundary with root), Repository (collection-like access), Domain Service (stateless biz logic), Domain Event (something happened). Bounded Context: explicit boundary per subdomain. Context Map: relationships between contexts (partnership, shared kernel, anticorruption layer).
