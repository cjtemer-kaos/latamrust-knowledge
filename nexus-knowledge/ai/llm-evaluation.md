# llm-evaluation

LLM evaluation: 1) Perplexity: prediction confidence. 2) BLEU/ROUGE: text similarity. 3) Human eval: gold standard. 4) LLM-as-judge: GPT evaluates outputs. 5) MMLU: 57 subjects benchmark. 6) HumanEval: code generation. 7) MATH: mathematical reasoning. 8) Arena: head-to-head comparisons. 9) Cost vs quality trade-off.
