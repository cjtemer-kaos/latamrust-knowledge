# incident-response-steps

Incident response paso a paso: 1) DETECT: monitoring alerta. 2) TRIAGE: SEV1 (down) → responder en 5min. SEV2 (degraded) → 30min. SEV3 (minor) → 4h. 3) DECLARE: Slack channel #incident-YYYY-MM-DD. 4) MITIGATE: rollback, feature flag off. 5) RESOLVE: fix deployado. 6) POST-MORTEM: 48h, blameless.
