# incident-response

Incident response: 1) Detect: monitoring alerts. 2) Triage: severity (SEV1-4). 3) Respond: incident commander, comms channel. 4) Mitigate: rollback, feature flag off, scale up. 5) Investigate: root cause analysis. 6) Resolve: fix deployed. 7) Review: post-mortem within 48h. 8) Prevent: action items. Blameless culture: focus on systems, not people.
