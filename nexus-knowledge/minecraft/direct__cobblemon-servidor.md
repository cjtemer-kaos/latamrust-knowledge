Setup de servidor Cobblemon Fabric para Minecraft 1.21.1: instalar el instalador de servidor de Fabric Loader, colocar el JAR Cobblemon-fabric y el JAR de Fabric API en la carpeta mods. Se genera la config en ./config/cobblemon/main.json. Comandos de debug utiles: /spawnpokemon y /givepokemon, ambos con opciones 'nature' y 'pokeball'. Para NeoForge el servidor usa el instalador NeoForge y requiere Kotlin for Forge en mods. El mod corre en cliente y servidor; en un servidor dedicado basta el JAR server-side para las mecanicas de spawn y captura.
