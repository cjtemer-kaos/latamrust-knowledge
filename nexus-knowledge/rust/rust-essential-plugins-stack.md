# rust-essential-plugins-stack

Essential uMod plugins for Rust servers 2026: NTeleportation (/home, /tpr, /town), Kits (starter/VIP kits), GatherManager (multiply gather rates), BetterChat (chat formatting, group tags), Vanish (admin invisibility), AdminRadar (ESP overlay), RemoverTool (remove structures), Backpacks (extra inventory), QuickSmelt (faster smelting), SkipNightVote (vote skip night), SignArtist (images to signs), NoEscape (blocks TP during combat/raid), Enhanced Ban System, Clans (team/clan system), Economics (currency), Shop (buy/sell), LustyMap (map UI), BotSpawn (NPC bots), RaidableBases (raidable NPC bases). Install: download .cs to oxide/plugins/, auto-loads. Config in oxide/config/. Data in oxide/data/. Permissions via oxide.grant. After every Facepunch update (first Thursday/month), reinstall uMod.
