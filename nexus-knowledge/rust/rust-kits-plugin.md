# rust-kits-plugin

Rust Kits by k1lly0u: predefined item kits for players. Features: auto-kits on spawn, /kit redeem, cooldowns, max uses, permissions, economy integration, GUI. Config: oxide/data/Kits/Kits.json (items, skin IDs, permissions, cooldowns). Admin: /kit new (from inventory), /kit delete, /kit edit, /kit give <player> <kit>. Player: /kit or /kit <name>. Supports skinned items. Works with economy plugins. Common: starter kits, VIP kits, event rewards.
