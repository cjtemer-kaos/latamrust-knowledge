Cobblemon (mod base) NO implementa cria/huevos nativos. Verificado en wiki.cobblemon.com via API de busqueda: no existen paginas 'Breeding', 'Eggs', 'Egg Group', 'Incense' ni 'Egg Move' (0 resultados; 'Egg' solo devuelve el item Lucky Egg). No hay bloque Daycare/Incubator ni items Incense/Soothe Bell para cria. No existe herencia de natures ni egg moves porque el sistema no esta implementado. La cria se obtiene con addons de terceros (p.ej. VeryScuffedCobblemonBreeding, CobblemonExtras). El unico bloque tipo rancho es el Pasture Block (ver item aparte). Fuente: wiki.cobblemon.com (wiki activa, revisado 2026-08).
