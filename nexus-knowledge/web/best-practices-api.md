# best-practices-api

API REST best practices: 1) Usar HTTP verbs correctamente (GET=lectura, POST=crear, PUT=actualizar, DELETE=borrar). 2) Códigos de estado HTTP apropiados. 3) Versionado (v1, v2). 4) Rate limiting. 5) Autenticación JWT/OAuth. 6) CORS configurado. 7) Documentación OpenAPI/Swagger. 8) Paginación en listados. 9) Error responses estandarizados. 10) Health check endpoint.
