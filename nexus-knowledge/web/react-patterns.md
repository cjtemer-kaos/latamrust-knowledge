# react-patterns

React patterns: 1) Components como funciones puras. 2) Hooks para state y side effects. 3) useMemo/useCallback para optimización. 4) Context para state global. 5) Custom hooks para lógica reutilizable. 6) Error Boundaries. 7) Suspense para lazy loading. 8) Portals para modals. 9) Refs para acceso al DOM. 10) Keys únicas en listas.
