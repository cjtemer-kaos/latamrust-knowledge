# WebRTC — Comunicacion en Tiempo Real

WebRTC (Web Real-Time Communication) es un estandar abierto para comunicacion peer-to-peer de audio, video y datos. Componentes: getUserMedia (captura camara/microfono), RTCPeerConnection (gestion conexion P2P), RTCDataChannel (canal de datos bidireccional). Senalizacion (signaling): intercambio de SDP (Session Description Protocol) y candidatos ICE entre pares - WebRTC no define protocolo de senalizacion, permite WebSocket, SIP, XMPP, MQTT. ICE (Interactive Connectivity Establishment) descubre la mejor ruta usando STUN (descubre IP publica) y TURN (relay cuando P2P es imposible). Arquitecturas: P2P (directa, pocos pares), SFU (Selective Forwarding Unit - relay selectivo, escalable, usado en Zoom/Meet), MCU (Multipoint Control Unit - mezcla, obsoleto). Codecs: VP8, VP9, H.264, AV1 (video); Opus (audio). Protocolos: SRTP/SRTCP (media encriptada), DTLS-SRTP (llaves), SCTP (data). Aplicaciones: videoconferencia, streaming, gaming, telemedicina.
