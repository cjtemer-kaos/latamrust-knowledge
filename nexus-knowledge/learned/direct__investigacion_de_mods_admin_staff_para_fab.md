Investigacion de mods admin/staff para Fabric 1.21.1:
1) AdminScope-mod - /spectate para moderadores. Server-side. GitHub: Abdo9616/AdminScope-mod
2) StaffList - muestra staff online con prefijos. Server-side. Modrinth: stafflist (no fabric)
3) BloodStoneCommandGenerator - genera comandos CoreProtect. GitHub: emielasda/BloodStoneCommandGenerator
4) AdminGui - GUI admin para Bukkit/Spigot, NO Fabric
5) admin-menu - menu admin para NeoForge, NO Fabric
6) fabric-admin-tool - ningun mod completo con GUI para Fabric 1.21.1
CONCLUSION: No existe un mod Fabric con GUI admin completa. Habria que crear uno propio o adaptar comandos existentes (Essential Commands + LP).
