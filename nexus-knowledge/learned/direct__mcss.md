MCSS (MC Server Soft): auto-relanza el server ~9-10s despues de cualquier stop (verificado 3x). runOnStartup=false. stopPrevention:Elevated. startupMethode=BatFile (NUNCA cambiar a CommandLine o MCSS pierde el server). Web API en puerto 25560 (enableWebApi:true). Configs en /d/SERVIDOR/resources/mcss_config.json y /d/SERVIDOR/servers/LATAMRUST COBBLEMON/mcss_server_config.json. El mod anticheat latamrust-core NO se debe tocar (anda bien).
