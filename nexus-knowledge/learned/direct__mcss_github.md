MCSS (Minecraft Server Soft) corriendo localmente gestiona start/stop del servidor. En GitHub: MinecraftServerControl/MCSS es un proyecto bash/Linux, no Windows. No hay equivalente Windows directo para copiar. Tiiffi/mcrcon es implementación de referencia en C del protocolo RCON. Para Python async: mcrcon (síncrono) o clientes async custom. Nexus usa cliente async TCP propio (minecraft_rcon.py) que funciona correctamente contra LATAMRUST.
