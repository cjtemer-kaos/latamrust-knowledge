OBTAINABLE|CobbleDex (Akkiruk/cobblemon-spawning-rei, alias CobbleDex REI/EMI/JEI): mod client-only para MC 1.21.1 + Cobblemon 1.7.1+ que convierte el recipe viewer en referencia completa: pestañas de Spawn Data (biomes tags, hora, clima, luz, altura, estructura, context, bucket, rarity, weight multipliers + anti-conditions), Evolution Chains (arboles familiares, items, form changes, requisitos), Forms/Mega/Gmax/regional, Item Drops, Stats, Moves, Pokedex info (abilities, egg groups, gender ratio, catch rate), Fossils, Type Chart, Natures y Riding Data. Funciona con REI 16+ / JEI 19+ / EMI 1.1+. Requiere Fabric Loader 0.15.0+, Fabric API 0.116.7+, Fabric Language Kotlin (o NeoForge 21.1.77+). No necesita instalarse en servidor; usa data sincronizada + fallback local, e indexa TABIEN datapacks ZIP en servidor. Incluye comando oculto /cobbledex export que genera xlsx multih‌oja para debug de un pack.
