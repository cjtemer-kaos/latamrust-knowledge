Text Placeholder API (Patbox) es la API de placeholders de Fabric, formato %modid:type% (docs: placeholders.pb4.eu). Soporta Simplified Text Format (estilo MiniMessage/HTML) para configs y chat. Config en config/placeholder-api/. Para Cobblemon: CobblemonPlaceholders (PokeSkies) anade 50+ placeholders (species, party, PokeDex, Molang queries), config en ./config/cobblemonplaceholders/config.json; requiere Fabric Language Kotlin + Fabric Permissions API + Cobblemon + TextPlaceholderAPI (o MiniPlaceholders). Reload: /cobblemonplaceholders reload (permiso cobblemonplaceholders.command.reload). Namespace recomendado para eco: cobeco:balance y cobeco:pco. Fuentes: modrinth.com/mod/cobblemonplaceholders, github.com/Patbox/TextPlaceholderAPI.
