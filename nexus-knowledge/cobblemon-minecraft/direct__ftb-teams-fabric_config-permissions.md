FTB Teams (Fabric) 1.21.1 - version estable ftb-teams-fabric-2101.1.10.jar (CurseForge/Modrinth). Requiere Fabric API + Architectury API + FTB Library (FTB GUI). No tiene config file propio; gestion via comandos: /ftbteams list, /ftbteams party, /ftbteams msg, /ftbteams info, /ftbteams server (OP), /ftbteams force-disband (OP). Para restringir creacion de equipos deniega con LuckPerms o FTB Ranks los nodos: command.ftbteams.party.create, command.ftbteams.party.join, command.ftbteams.party.invite, command.ftbteams.party.leave. Con FTB Chunks controla por claim: mob griefing, block breaking, block placing, block interaction. Server teams = gestion de servidor, no pueden unirse jugadores. Fuentes: docs.feed-the-beast.com/mod-docs/mods/suite/Teams + github.com/FTBTeam/FTB-Teams.
