Universal Shops (Patbox, modrinth/mod/universal-shops, GitHub Patbox/UniversalShops): mod de tiendas tipo vending para servers Fabric/Quilt, solo server-side (funciona con cliente vanilla/compat). Para sustituir tiendas basadas en plugin no aplicable a Fabric, o como alt de Cobblemon Economy. Version 1.x compatible 1.21.x (1.10.x para 1.21.4-1.21.5; 1.9.x para 1.21.2-1.21.3; la ultima serie soporta 1.21.x). Craftable: bloque Trade Shop = 4 planks + 1 lana + 1 lingote de hierro; se coloca encima/adyacente a un contenedor (cofre) y se configura la GUI (que stock se vende y precio; opcional soporte de hoppers y holograma). Tambien incluye Admin Trade Shop para admins/map makers (misma config). Usa Common Protection API para verificar acceso al cofre fuente: se recomienda un mod de proteccion GOML (modrinth/mod/goml-reserved) o HTM (modrinth/mod/htm). No requiere plugin de economia externo: el stock se toma del contenedor. Fuentes: GitHub README + Modrinth + CurseForge.
