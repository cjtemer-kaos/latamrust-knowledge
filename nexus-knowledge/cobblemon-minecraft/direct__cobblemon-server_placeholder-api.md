Placeholder API para Fabric 1.21.1 = Text Placeholder API de Patbox (modrinth/mod/placeholder-api, proyecto eXts2L7r). Version exacta para 1.21/1.21.1: placeholder-api-2.4.2+1.21.jar (Fabric+Quilt, client_or_server). Formato de placeholders: %modid:type% o %modid:type/extra% (ej. %cobblemon:...%). Es una libreria JIJ (jar-in-jar): la mayoria de mods la incluyen empaquetada, pero se puede descargar standalone. No requiere config para uso basico; los mods compatibles la usan para mostrar info (dinero, equipo, stats) en mensajes/GUI. Documentacion: https://placeholders.pb4.eu (user/general, user/default-placeholders, user/mod-placeholders, quicktext). APIs dev: PlaceholderAPI.register, parseString/parseText. Fuente verificada: API Modrinth (versions response) + GitHub Patbox/TextPlaceholderAPI + guia de placeholders.pb4.eu.
