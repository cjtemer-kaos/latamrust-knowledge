# db-indexing

Database indexing: 1) B-tree: range queries, ORDER BY. 2) Hash: equality lookups. 3) GIN: full-text, arrays. 4) GiST: geometric, full-text. 5) Composite indexes: column order matters. 6) Covering indexes: include columns. 7) Partial indexes: WHERE clause. 8) BRIN: large sequential tables.
