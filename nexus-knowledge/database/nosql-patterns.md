# nosql-patterns

NoSQL patterns: 1) Document (MongoDB): flexibilidad, nested objects. 2) Key-Value (Redis): cache, sessions. 3) Column-family (Cassandra): time series, high write. 4) Graph (Neo4j): relaciones complejas. 5) Event sourcing: store events, derive state. 6) CQRS: read/write models separados. 7) Saga pattern para transacciones distribuidas.
