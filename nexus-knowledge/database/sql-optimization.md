# sql-optimization

SQL optimization: 1) EXPLAIN ANALYZE para ver query plan. 2) Índices en WHERE, JOIN, ORDER BY. 3) Covering indexes. 4) Avoid SELECT *. 5) LIMIT para paginación. 6) EXISTS > IN para subqueries. 7) JOIN order importa. 8) Window functions para analytics. 9) Materialized views para queries lentas. 10) Connection pooling (pgBouncer).
