# vector-databases

Vector databases: 1) Pinecone: managed, easy. 2) Weaviate: open-source, multi-modal. 3) Chroma: lightweight, local. 4) FAISS: Facebook, CPU/GPU. 5) Milvus: distributed, scalable. 6) pgvector: PostgreSQL extension. 7) Qdrant: Rust-based, fast. Comparison: Pinecone=easiest, Weaviate=most features, Chroma=lightest, FAISS=fastest raw.
