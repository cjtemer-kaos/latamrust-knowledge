# database-patterns

Database patterns: 1) Indexación en columnas frecuentemente consultadas. 2) Normalización hasta 3NF. 3) Denormalización para reads frecuentes. 4) Connection pooling. 5) Query optimization con EXPLAIN. 6) Migrations versionadas. 7) Backup automático. 8) Read replicas para escalar. 9) Sharding para datos masivos. 10) Cache con Redis/Memcached.
