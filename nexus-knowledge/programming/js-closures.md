# js-closures

Closures en JavaScript: una función que recuerda su scope léxico. 1) Data privacy: variables encapsuladas. 2) Factory functions: crear funciones con estado. 3) Callbacks y event handlers. 4) Module pattern: IIFE + closure. 5) Currying: f(a)(b). 6) Memoización. Cuidado: closures en loops con var (solución: let).
