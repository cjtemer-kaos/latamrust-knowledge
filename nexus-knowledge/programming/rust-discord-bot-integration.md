# rust-discord-bot-integration

Discord + Rust integration approaches: 1) uMod plugins (DiscordChat, DiscordMessages, DiscordLink) bridge chat, server events. 2) Oxide Discord Extension. 3) External bots via WebRCON (port 28016 + password). Features: bidirectional chat bridge, player count/status, admin commands from Discord, wipe schedules, restart announcements. Tebex webhooks + Discord for purchase notifications. Useful: chat bridge, admin alerts, purchase verification. RCON password must be secured.
