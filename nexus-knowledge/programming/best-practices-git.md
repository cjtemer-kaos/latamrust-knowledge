# best-practices-git

Git best practices: 1) Branching strategy (GitFlow o trunk-based). 2) Commits atómicos y descriptivos. 3) Conventional Commits (feat:, fix:, chore:). 4) Squash antes de merge. 5) .gitignore completo. 6) No commitear secrets. 7) Pull requests con descripción. 8) CI/CD en PRs. 9) Tags para releases. 10) Protected branches (main).
