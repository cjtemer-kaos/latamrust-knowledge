# py-error-handling

Error handling en Python: 1) EAFP > LBYL (try/except > if checks). 2) Excepciones específicas, nunca bare except. 3) Exception groups para múltiples errores. 4) Context manager para cleanup. 5) Logging de excepciones con exc_info=True. 6) Re-raising con raise sin args preserva traceback. 7) Custom exceptions para dominios específicos.
