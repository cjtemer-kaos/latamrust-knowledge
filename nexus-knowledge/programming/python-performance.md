# python-performance

Python performance: 1) Profiling: cProfile, line_profiler. 2) Caching: @lru_cache, functools.cache. 3) Generators for memory. 4) NumPy for numerical (C-backed). 5) multiprocessing for CPU-bound. 6) asyncio for I/O-bound. 7) __slots__ for memory. 8) String joining > concatenation. 9) Set lookups > list searches. 10) Avoid global variables.
