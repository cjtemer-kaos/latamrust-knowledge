# git-advanced

Git advanced: 1) Interactive rebase: git rebase -i HEAD~5. 2) Bisect: git bisect start/good/bad. 3) Worktrees: git worktree add ../feature feature-branch. 4) Stash: git stash push -m 'WIP'. 5) Cherry-pick: git cherry-pick <commit>. 6) Reflog: git reflog recover lost commits. 7) Submodules: git submodule update --init.
