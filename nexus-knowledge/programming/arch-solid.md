# arch-solid

SOLID Principles: 1) Single Responsibility: una razón para cambiar. 2) Open/Closed: abierto para extensión, cerrado para modificación. 3) Liskov Substitution: subtipos deben ser sustituibles. 4) Interface Segregation: interfaces pequeñas. 5) Dependency Inversion: depender de abstracciones. Resultado: código mantenible, testeable, extensible.
