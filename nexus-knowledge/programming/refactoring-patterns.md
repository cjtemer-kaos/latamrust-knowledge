# refactoring-patterns

Refactoring patterns: 1) Extract Method: pull code into function. 2) Rename: make names descriptive. 3) Move Method: right class. 4) Replace Temp with Query. 5) Introduce Parameter Object. 6) Replace Conditional with Polymorphism. 7) Decompose Conditional. 8) Replace Magic Numbers with Named Constants. Tools: IDE refactor, manual + tests.
