# py-type-hints

Type hints en Python: 1) from typing import Optional, Union, List, Dict, Tuple. 2) Python 3.10+: list[str] en vez de List[str]. 3) Protocol para structural typing. 4) TypeVar para generics. 5) Literal para valores específicos. 6) Annotated para metadata. 7) mypy o pyright para verificación estática. 8) TypedDict para dicts con estructura conocida.
