# logging-best-practices

Logging best practices: 1) Structured logging (JSON). 2) Log levels: DEBUG < INFO < WARN < ERROR < FATAL. 3) Request ID for tracing. 4) Correlation IDs across services. 5) PII masking. 6) Log rotation. 7) Centralized aggregation. 8) Don't log sensitive data. 9) Use f-strings, not % formatting. 10) Exception logging with full traceback.
