# async-patterns

Async programming patterns: 1) async/await para claridad. 2) Promise.all para paralelo. 3) Promise.allSettled para tolerancia. 4) Circuit breaker para servicios externos. 5) Retry con exponential backoff. 6) Timeout en cada operación. 7) Rate limiting. 8) Queue para procesamiento secuencial. 9) Semaphore para concurrencia limitada. 10) Cancelación cooperativa.
