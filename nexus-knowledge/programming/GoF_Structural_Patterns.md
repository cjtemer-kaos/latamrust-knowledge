# GoF Structural Patterns

Adapter: convert interface -- class Adapter(Target): wraps Adaptee, delegates calls. Decorator (structural): add behavior without subclassing via composition/wrapping. Facade: simplified interface to complex subsystem (requests over urllib). Proxy: surrogate for lazy init, caching, access control. Composite: treat individual objects and compositions uniformly (tree). Bridge: decouple abstraction from implementation. Flyweight: share fine-grained objects.
