# py-metaclasses

Metaclasses en Python: son clases que crean clases. type es la metaclass default. 1) class Meta(type): def __new__(cls, name, bases, dict). 2) ABC usa ABCMeta. 3) Singleton pattern con metaclass. 4) Validación automática de atributos. 5) Registro automático de subclases. Usar solo cuando los decoradores/metaclases no alcanzan.
