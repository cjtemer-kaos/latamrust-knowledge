# async-communication

Async communication: 1) Write clearly the first time. 2) Context: explain WHY, not just WHAT. 3) Action items: who, what, when. 4) Status updates: progress, blockers, next steps. 5) Don't block: proceed with best assumption. 6) Documentation over meetings. 7) Loom/video for complex topics. 8) Response SLA: 4h for async teams.
