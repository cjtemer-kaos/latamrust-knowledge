# profiling-python

Profiling Python: 1) cProfile: python -m cProfile script.py. 2) line_profiler: @profile decorator. 3) memory_profiler: @profile for RAM. 4) py-spy: sampling profiler, no overhead. 5) snakeviz: visualización de profiles. 6) timeit: micro-benchmarks. 7) pytest-benchmark: benchmarks en tests.
