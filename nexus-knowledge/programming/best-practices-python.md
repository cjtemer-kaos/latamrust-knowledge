# best-practices-python

Python best practices: 1) Usar type hints. 2) virtualenv para cada proyecto. 3) pip-tools o poetry para dependencias. 4) black/ruff para formateo. 5) pytest para tests. 6) logging en vez de print. 7) Context managers para recursos. 8) async/await para I/O bound. 9) dataclasses o pydantic para modelos. 10) __all__ en módulos públicos.
