# GoF Behavioral Patterns

Observer: one-to-many notify on state change. Strategy: interchangeable algorithms (context delegates). Command: encapsulate request as object (undo, queue, log). Iterator: sequential access without exposing representation (Python __iter__/__next__). Chain of Responsibility: pass request along handler chain (middleware). State: object alters behavior on internal state change. Mediator: centralize communication between objects. Memento: capture/restore internal state.
