# py-patterns

Python patterns: 1) Singleton: _instance = None + __new__. 2) Factory: create(**kwargs) retorna subclase. 3) Strategy: pasar callable como parámetro. 4) Observer: lista de callbacks. 5) Command: encapsular acción en objeto. 6) Adapter: interface compatible. 7) Facade: interfaz simple sobre subsistema complejo. 8) Proxy: controlar acceso a objeto.
