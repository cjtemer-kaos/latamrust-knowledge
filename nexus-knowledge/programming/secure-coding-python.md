# secure-coding-python

Secure coding Python: 1) No eval()/exec() on untrusted input. 2) Parameterized SQL queries. 3) Input validation with pydantic. 4) Output encoding. 5) Secrets in env vars, not code. 6) HTTPS only. 7) Content-Security-Policy. 8) Rate limiting. 9) Logging (no secrets). 10) Dependency scanning.
