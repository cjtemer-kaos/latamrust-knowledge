# python-patterns

Python design patterns: 1) Singleton (get_instance). 2) Factory (create_object). 3) Observer (event-driven). 4) Strategy (interchangeable algorithms). 5) Decorator (wrap behavior). 6) Context Manager (with statement). 7) Iterator (for loop). 8) Command (encapsulate actions). 9) State (有限状态机). 10) MVC/MVVM para UI.
