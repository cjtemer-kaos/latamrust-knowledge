MANUAL COBBLEMON RANKED (es, 2026-08-20): Sistema ranking Elo + matchmaking para Cobblemon 1.21.1, server-side, tecla X GUI. 3 modos: Singles/Doubles/2v2singles. Comandos jugador: /rank gui, gui_top, gui_info, gui_queue, queue join [formato], queue leave, status, top, info, season, pokemon_usage. Admin (OP): gui_reward, gui_reset, reset <jug> <formato>, reward, season end, reload, setseasonname. Placeholders: %Cobblemon_ranked:elo%, rank_title%, win_rate%, etc + sufijos _singles/_doubles/_2v2singles. Config: config/cobblemon_ranked/cobblemon_ranked.json (defaultLang, defaultFormat, minTeamSize, arenas, umbrales elo, temporadas, enableTeamPreview). Cross-server (v1.2.0+, solo singles): enableCrossServer, cloudServerId, /rank cross start|stop|chat|join singles|leave, battle move/switch/forfeit. Desconexion=derrota (pierde Elo). Adecuado para server solo-PvP Pokemon. Manual .docx en Escritorio: Manual-Cobblemon-Ranked-ES.docx
