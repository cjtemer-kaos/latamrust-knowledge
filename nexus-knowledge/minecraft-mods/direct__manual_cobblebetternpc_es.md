MANUAL COBBLE BETTER NPC (es, 2026-08-20): Sistema avanzado para crear NPCs interactivos en server Cobblemon, server-side required, config JSON. Features: NPCs personalizados (nombre, titulo, comportamiento); dialogo con arbol de ramas, multiples respuestas y condiciones; acciones/eventos (comandos al interactuar, segun permisos o progreso); compatible con CobbleMissions; multi-NPC y multi-mundo. Estructura JSON NPC: {type:dialogue, resourceIdentifier, names[], interaction:[{name, with, permission, dialogue}]}. Ejemplo: NPC 'Professor Oak' con interacciones segun permiso cobblebetternpc.oak.finish. permission vacio=abierta a todos. 'dialogue' = id del dialogo (ej cobblebetternpc:oak_intro). ATENCION: en Modrinth client_side=unsupported (verificar compatibilidad, requiere el mod en cliente para la parte visual). Server actual usa Easy NPC para NPCs existentes.
