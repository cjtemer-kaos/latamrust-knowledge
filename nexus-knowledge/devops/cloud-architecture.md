# cloud-architecture

Cloud architecture: 1) Stateless services para escalar horizontal. 2) Load balancing. 3) Auto-scaling policies. 4) Multi-AZ para disponibilidad. 5) S3 para almacenamiento estático. 6) CloudFront/CDN para edge. 7) RDS para datos relacionales. 8) DynamoDB para NoSQL. 9) SQS/SNS para messaging. 10) Lambda para event-driven.
