# Service mesh es una capa de infraestructura para gestionar comunicacion entre microservicios en Kube

Service mesh es una capa de infraestructura para gestionar comunicacion entre microservicios en Kubernetes: confiabilidad, observabilidad y seguridad sin modificar codigo. Arquitectura: data plane (proxies sidecar) + control plane (configuracion centralizada). Istio: proxy Envoy (C++), control plane
