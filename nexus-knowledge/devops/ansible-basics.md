# ansible-basics

Ansible basics: 1) Agentless (SSH). 2) Playbooks: YAML tasks. 3) Roles: reusable components. 4) Inventory: target hosts. 5) Modules: apt, yum, copy, template, service. 6) Handlers: triggered by notify. 7) Variables: group_vars, host_vars. 8) Vault: encrypted secrets. 9) Idempotent: run multiple times safely.
