# kubernetes-basics

Kubernetes essentials: 1) Pod: unidad mínima (1+ containers). 2) Deployment: replica management, rolling updates. 3) Service: load balancing interno (ClusterIP, NodePort, LoadBalancer). 4) Ingress: routing HTTP externo. 5) ConfigMap/Secret: configuración. 6) PersistentVolume: almacenamiento. 7) HPA: auto-scaling. Comando: kubectl get pods -o wide.
