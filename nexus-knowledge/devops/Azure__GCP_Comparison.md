# Azure & GCP Comparison

Azure: VMs (Virtual Machines), Functions (serverless), AKS (K8s plus Azure AD integration), Blob Storage (block/page/append blobs), Cosmos DB (multi-model NoSQL), SQL Database (managed), DevOps (Boards+Pipelines+Repos). GCP: Compute Engine (VMs), Cloud Functions (2nd gen runs on Cloud Run), GKE (K8s with Autopilot), Cloud Storage (uniform/bucket), Firestore (NoSQL), BigQuery (serverless data warehouse). Key diff: AWS dominates market share, Azure best for MS shops, GCP for data/ML (BigQuery, Vertex AI).
