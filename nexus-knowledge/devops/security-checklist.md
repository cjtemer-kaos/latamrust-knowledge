# security-checklist

Security checklist: 1) Input validation en cada endpoint. 2) Parameterized queries contra SQL injection. 3) Output encoding contra XSS. 4) CSRF tokens. 5) Secure headers (HSTS, CSP, X-Frame-Options). 6) Secrets en vault, no en código. 7) Principle of least privilege. 8) Audit logging de acciones sensibles. 9) Dependency vulnerability scanning. 10) Penetration testing regular.
