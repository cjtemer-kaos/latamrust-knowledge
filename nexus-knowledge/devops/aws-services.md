# aws-services

AWS Core Services: 1) EC2: VMs. 2) S3: object storage. 3) RDS: managed DB. 4) Lambda: serverless functions. 5) API Gateway: managed APIs. 6) SQS/SNS: messaging. 7) CloudFront: CDN. 8) EKS: managed K8s. 9) IAM: access control. 10) CloudWatch: monitoring. Patrón: Lambda + API Gateway + DynamoDB para APIs serverless.
