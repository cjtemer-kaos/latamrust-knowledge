# best-practices-devops

DevOps/CI/CD best practices: 1) Infrastructure as Code. 2) CI en cada PR. 3) CD automatizado a staging/prod. 4) Rollback automático. 5) Feature flags para releases. 6) Blue-green o canary deployments. 7) Monitoring y alerting. 8) Log aggregation. 9) Incident response playbook. 10) Post-mortem después de incidents.
