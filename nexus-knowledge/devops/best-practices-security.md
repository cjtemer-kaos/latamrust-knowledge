# best-practices-security

Seguridad en desarrollo: 1) Nunca hardcodear secrets. 2) Usar variables de entorno. 3) Validar input del usuario. 4) Sanitizar output (XSS). 5) Parameterized queries (SQL injection). 6) HTTPS siempre. 7) CORS restrictivo. 8) Rate limiting. 9) Audit logging. 10) Dependency scanning (dependabot/snyk).
