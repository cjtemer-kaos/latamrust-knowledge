# best-practices-docker

Docker best practices: 1) Usar multi-stage builds. 2) Imágenes base mínimas (alpine). 3) .dockerignore para excluir archivos. 4) No correr como root. 5) Variables de entorno para configuración. 6) Docker Compose para desarrollo. 7) Health checks en Dockerfile. 8) Logs a stdout/stderr. 9) Volumenes para datos persistentes. 10) Redes Docker para aislamiento.
