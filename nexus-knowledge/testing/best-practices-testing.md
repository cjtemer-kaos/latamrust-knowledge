# best-practices-testing

Testing best practices: 1) Test Pyramid: muchas unit, pocas integration, pocas E2E. 2) AAA pattern (Arrange, Act, Assert). 3) Tests determinísticos (sin side effects). 4) Mock de dependencias externas. 5) Coverage > 80%. 6) Tests en CI/CD. 7) TDD cuando sea práctico. 8) Mutation testing para validar tests. 9) Test data factories. 10) Parallel test execution.
