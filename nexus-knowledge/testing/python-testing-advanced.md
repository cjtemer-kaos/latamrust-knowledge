# python-testing-advanced

Advanced Python testing: 1) fixtures: setup/teardown with pytest. 2) parametrize: test multiple inputs. 3) mocking: unittest.mock for isolation. 4) Property-based testing: hypothesis. 5) Mutation testing: mutmut. 6) Coverage: pytest-cov. 7) Async testing: pytest-asyncio. 8) Snapshot testing. 9) Contract testing for APIs.
