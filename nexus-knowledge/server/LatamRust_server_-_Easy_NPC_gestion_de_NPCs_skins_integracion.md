# LatamRust server - Easy NPC, gestion de NPCs, skins, integracion

LATAMRUST SERVER - Gestion de NPCs con Easy NPC

MOD: Easy NPC v7.4.1
UBICACION: D:\SERVIDOR\servers\LATAMRUST COBBLEMON\mods\

FUNCIONES:
- Crear NPCs con dialogos personalizados
- Asignar skins custom a NPCs
- Configurar rutas y comportamiento
- Integracion con Cobblemon (NPCs trainers)

SKINS DE NPCs:
- Directorio: config/easy_npc/skin/
- 38 tipos de NPC (humanoid, villager, zombie, etc.)
- 325 skins templates + Pokemon tematicas
- Los admins crean skins con UUIDs en el nombre
- Sincronizar via launcher (Metodo 2 del plan)

CREAR NPC:
1. Usar /npc create en el juego
2. Seleccionar tipo de NPC
3. Asignar dialogo
4. Asignar skin (seleccionar de templates)
5. Configurar comportamiento

SKINS CUSTOM:
- Los admins suben PNGs a config/easy_npc/skin/{tipo}/
- El mod las guarda con UUID del NPC
- Otros jugadores necesitan el mismo archivo
- Solucion: sincronizar via launcher o Metodo Online

INTEGRACION CON COBBLEMON:
- NPCs pueden ser trainers
- Dialogos personalizados para batallas
- Integracion con sistema de entrenadores
