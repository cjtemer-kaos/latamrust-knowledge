# nexus-latamrust-gemas-functions

8 custom latamrust-specific gemas in SuperNEXUS: 1) advanced_plugin_editor - GUI editor for uMod/Carbon plugin configs (.json). 2) combatlog_analyst - parses Rust combat logs, analyzes deaths/damage/weapons. 3) discord_manager - manages Discord bot integration (chat bridge, alerts, whitelist). 4) map_editor - visual map zone editor with ZoneManager integration. 5) player_watcher - monitors player activity, flags suspicious behavior. 6) plugin_configurator - installs/configures uMod plugins via web UI. 7) rcon_commander - executes RCON commands, manages server console. 8) tebex_sync - syncs Tebex purchases, manages store listings, checks pending commands. All integrated with Director orchestration and latamrust-nexus UI (D:\ias\proyectos\latamrust-nexus).
