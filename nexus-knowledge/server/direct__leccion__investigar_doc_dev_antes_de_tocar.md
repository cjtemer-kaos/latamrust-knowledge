# Direct: Leccion: investigar doc dev antes de tocar mods

Category: Server
Tags: leccion, investigar, config
Created: 2026-08-20T12:59:51.660727

---

LECCION APRENDIDA (usuario, 2026-08-20): INVESTIGAR SIEMPRE la documentacion/codigo del desarrollador (Modrinth body, GitHub, wiki) ANTES de tocar un mod/config. Casi todo mod tiene una opcion de config que resuelve el problema sin parches complejos. Ejemplo: el spam '[LazyChunkLoad] Tick:... CPU:MSPT' de LazyChunkLoad lo resolvia una opcion 'performance_tips' en lazychunkload.json, NO un filtro de log4j. Aplicar esta leccion siempre.
