# LatamRust server - resource packs, gestion, instalacion

LATAMRUST SERVER - Gestion de resource packs

UBICACION: D:\SERVIDOR\servers\LATAMRUST COBBLEMON\resourcepacks\

RESOURCE PACKS INSTALADOS (40+):
- COBBLEVERSE RP.zip (resource pack principal)
- COBBLEVERSE Soundtrack.zip (musica custom)
- COBBLEVERSE RCTmod.zip (Rare Candy Trainer)
- CavsCobbleMons RP.zip (texturas Pokemon)
- Cobblemon Interface.zip (UI de Cobblemon)
- CobbleMotion RP.zip (animaciones)
- Comforts Modernized.zip
- Classic Grass.zip
- E19 Cobblemon Minimap Icons.zip
- EeveelutionsReimagined RP.zip
- Fresh Animations/Icons/Moves.zip
- GlitchDex RP.zip
- Low Fire.zip
- Original Pokemon Battle Music.zip
- yawp-spanish-lang.zip
- Y muchas mas (40+ total)

CONFIGURACION:
- initial-enabled-packs: lista de packs habilitados
- require-resource-pack=false: no obliga a descargar
- Los packs se descargan automaticamente al entrar al server

AGREGAR NUEVO RESOURCE PACK:
1. Copiar ZIP a D:\SERVIDOR\servers\LATAMRUST COBBLEMON\resourcepacks\
2. Agregar nombre a initial-enabled-packs en server.properties
3. Reiniciar server para que lo cargue

IMPORTANTE:
- Los resource packs NO necesitan sync via launcher
- Se descargan del server automaticamente
- Solo las custom skins de Easy NPC necesitan sync manual
