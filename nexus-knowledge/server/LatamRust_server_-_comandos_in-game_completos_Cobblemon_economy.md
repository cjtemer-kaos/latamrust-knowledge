# LatamRust server - comandos in-game completos, Cobblemon, economy

LATAMRUST SERVER - Comandos in-game completos

TELETRANSPORTE:
- /spawn: ir al spawn principal
- /home: ir a casa guardada
- /sethome: establecer casa actual
- /delhome <nombre>: eliminar casa
- /homes: listar casas
- /tpa <player>: pedir teletransporte
- /tpahaceptar: aceptar TPA
- /tpadenegar: rechazar TPA
- /back: volver al ultimo lugar
- /warp <nombre>: ir a un warp
- /setwarp <nombre>: crear warp
- /delwarp <nombre>: eliminar warp
- /warps: listar warps

COBBLEMON:
- /pokegive <player> <pokemon>: dar pokemon
- /pokespawn <pokemon>: spawnear pokemon en tu posicion
- /pokeheal: curar todos tus pokemon
- /pc: abrir PC virtual (caja de almacenamiento)
- /pokecheck <player>: ver pokemon de otro jugador
- /pokedex: ver pokedex
- /pokebattle <player>: iniciar batalla

ECONOMIA:
- /balance: ver tu saldo
- /pay <player> <amount>: pagar a otro jugador
- /shop: abrir tienda
- /sell <item> <amount>: vender items
- /buy <item> <amount>: comprar items
- /baltop: ranking de saldo

CONSTRUCCION:
- //set <block>: reemplazar seleccion con bloque
- //replace <old> <new>: reemplazar bloques
- //copy: copiar seleccion
- //paste: pegar seleccion
- //undo: deshacer
- //wand: obtener herramienta de seleccion
- //pos1: posicion 1
- //pos2: posicion 2

ADMIN:
- /gc: info del server (TPS, memoria, etc)
- /lag: ver lag del server
- /broadcast <msg>: anunciar a todos
- /kick <player> [reason]: expulsar jugador
- /ban <player> [reason]: banear jugador
- /pardon <player>: desbanear jugador
- /gamemode <mode> <player>: cambiar modo de juego
- /tp <player> <target>: teletransportar
- /give <player> <item> [amount]: dar items
- /effect <player> <effect> [dur] [level]: dar efectos
- /clear <player>: limpiar inventario
- /seed: ver semilla del mundo
- /time <set|add> <value>: cambiar tiempo
- /weather <clear|rain|thunder>: cambiar clima
- /difficulty <level>: cambiar dificultad
- /save-all: guardar mundo
- /stop: apagar server

COBBLEMON EXTRAS:
- /pokegive <player> <pokemon> shiny: dar pokemon shiny
- /pokegive <player> <pokemon> level <n>: dar pokemon con nivel
- /pokegive <player> <pokemon> perfect: dar pokemon perfecto
- /pc release <slot>: liberar pokemon
- /pc store <slot>: almacenar pokemon
- /pc party: ver equipo

IMPORTANTE:
- Comandos de LuckPerms NO funcionan via RCON
- Usar web-editor en localhost:8080 para LuckPerms
- O ejecutar desde chat in-game como OP
