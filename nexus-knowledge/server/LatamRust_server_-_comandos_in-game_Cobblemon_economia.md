# LatamRust server - comandos in-game, Cobblemon, economia

LATAMRUST SERVER - Comandos in-game y funciones

COMANDOS ESPECIALES (via chat):
- /spawn: ir al spawn
- /home: ir a casa
- /sethome: establecer casa
- /tpa <player>: pedir teletransporte
- /tpahaceptar: aceptar TPA
- /back: volver al ultimo lugar
- /warp <nombre>: ir a un warp
- /setwarp <nombre>: establecer warp

COBBLEMON:
- /pokegive <player> <pokemon>: dar pokemon
- /pokespawn <pokemon>: spawnear pokemon
- /pokeheal: curar todos los pokemon
- /pc: abrir PC virtual
- /pokecheck: verificar pokemon

ECONOMIA:
- /balance: ver saldo
- /pay <player> <amount>: pagar
- /shop: tienda

ADMIN:
- /gc: ver info del server
- /tps: ver TPS
- /lag: ver lag del server
- /broadcast <msg>: anunciar a todos

IMPORTANTE:
- Comandos de LuckPerms NO funcionan via RCON
- Usar web-editor en localhost:8080 para LuckPerms
- O ejecutar desde chat in-game como OP
