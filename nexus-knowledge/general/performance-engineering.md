# performance-engineering

Performance engineering: 1) Measure first (profiling). 2) Latency percentiles (p50, p95, p99). 3) Throughput (RPS). 4) Bottleneck analysis. 5) Caching strategies (app, DB, CDN). 6) Connection pooling. 7) Async I/O. 8) Batch processing. 9) Lazy loading. 10) Code optimization (algorithm > micro-optimization). Tools: cProfile, py-spy, flame graphs.
