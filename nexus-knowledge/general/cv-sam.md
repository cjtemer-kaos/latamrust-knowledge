# cv-sam

Segment Anything Model (SAM): 1) Zero-shot segmentation. 2) Point prompts: click on object. 3) Box prompts: bounding box. 4) Text prompts: describe object. 5) Auto-mask: segment everything. 6) Use cases: image editing, data labeling, medical imaging. 7) SAM 2: video support. 8) FastSAM: real-time variant.
