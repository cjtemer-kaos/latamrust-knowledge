# code-review

Code review checklist: 1) Funcionalidad correcta. 2) Tests incluidos. 3) Code style consistente. 4) No code smells (long methods, duplicated code). 5) Seguridad (no secrets, input validation). 6) Performance (no N+1 queries). 7) Error handling completo. 8) Documentation actualizada. 9) Breaking changes identificados. 10) CI passing.
