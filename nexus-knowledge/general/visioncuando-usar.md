# vision/cuando-usar

Cuando el usuario pida generar/dibujar/crear una imagen, ilustracion, concept art, retrato, paisaje, logo, diagrama visual, o cualquier solicitud visual: usar POST /api/vision/generate. Palabras clave: dibuja, genera, crea imagen, illustration, artwork, concept art, imagen de, picture of, retrato de, paisaje de, logo de. NO usar para: analisis de imagenes existentes (usar vision_analyze), describir imagen (usar describe_image).
