# tech-writing

Technical writing: 1) Structure: Problem → Solution → Implementation. 2) Audience-aware: dev vs PM vs user. 3) Diagrams > walls of text. 4) Code examples with context. 5) Version-controlled docs. 6) README.md: what, why, how, examples. 7) API docs: OpenAPI/Swagger. 8) Changelog: Keep a Changelog format.
