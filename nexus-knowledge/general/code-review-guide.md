# code-review-guide

Code review guide: 1) What to check: correctness, security, performance, readability. 2) How to comment: be specific, suggest alternatives. 3) Nit vs important: distinguish severity. 4) Praise good code too. 5) Respond constructively to feedback. 6) Automate what can be automated (linters). 7) Review in small batches (<400 lines). 8) Time-box reviews.
