# prompt-engineering

Prompt Engineering avanzado: 1) System prompt define el rol. 2) Few-shot examples mejoran calidad. 3) Chain of Thought para razonamiento. 4) Delimitadores claros (XML tags, ---). 5) Instructions específicas y accionables. 6) Temperature baja para factual, alta para creative. 7) Max tokens suficiente. 8) Evitar ambigüedad. 9) Iterar y refinar prompts. 10) Evaluar con métricas objetivas.
