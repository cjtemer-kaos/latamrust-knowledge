# encryption

Encryption: 1) Symmetric (AES-256): misma key para encrypt/decrypt. 2) Asymmetric (RSA/ECC): public/private key pair. 3) Hashing: SHA-256, bcrypt, argon2. 4) HMAC: hash + key para integridad. 5) TLS 1.3: transporte seguro. 6) End-to-end: client-side encryption. 7) Key rotation: cambiar keys regularmente. 8) HSM para key storage.
