# grok-build-patrones-clave

GROK BUILD (SpaceXAI) PATRONES CLAVE para Nexus: 1) ACTION_SAFETY: evaluar reversibilidad antes de ejecutar. Acciones locales/reversibles (editar archivos, test) se hacen libre. Acciones destructivas/irreversibles (rm -rf, force-push, borrar branches) requieren confirmacion. 2) PREAMBLE MESSAGES: describir que vas a hacer ANTES de la tool call, agrupar acciones relacionadas, mantener conciso 8-12 palabras. 3) AGENTS.md SPEC: archivos de instrucciones por directorio, scope = subtree, nested tiene precedencia, instrucciones directas del usuario ganan. 4) HASHLINE WORKFLOW: edicion por anchors ANCHOR-CONTENT, batch atomico (si un anchor esta stale, todos se rechazan). 5) SUBAGENT: focused worker, no expandir scope, paralelizar tool calls independientes. 6) OUTPUT EFFICIENCY: escribir como blog tecnico, conciso, markdown activo. 7) BACKGROUND TASKS: monitoreo de procesos largos via polling.
