# best-practices-code

Mejores prácticas de programación: 1) Código legible > código clever. 2) Nombres descriptivos (no abreviar). 3) Funciones pequeñas (< 30 líneas). 4) Single Responsibility Principle. 5) DRY (Don't Repeat Yourself). 6) KISS (Keep It Simple). 7) YAGNI (You Aren't Gonna Need It). 8) Code review obligatorio antes de merge. 9) Tests antes de commit. 10) Commit messages descriptivos (Conventional Commits).
