# Prompt Engineering Advanced Techniques

Chain-of-Thought (CoT): 'Let's think step by step' for reasoning tasks. Few-shot: provide 2-5 examples. Zero-shot CoT: 'First, ... Then, ... Finally, ...'. Tree-of-Thoughts (ToT): explore multiple reasoning branches. ReAct: reasoning + acting (thought->action->observation->thought). Self-Consistency: sample multiple CoT paths, vote on answer. Structured prompts: XML/JSON output specification. Persona: 'You are an expert ...' for domain targeting. Negative prompts: avoid certain behaviors. Temperature: 0 for factual, 0.7 for creative, >1 for diverse.
