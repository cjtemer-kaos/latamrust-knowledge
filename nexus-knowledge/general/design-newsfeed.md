# design-newsfeed

News feed: 1) Pull model: user requests feed. 2) Push model: fan-out on write. 3) Hybrid: push for celebrities, pull for others. 4) Ranking: EdgeRank algorithm. 5) Caching: precomputed feeds. 6) Pagination: cursor-based. 7) Media: lazy loading, CDN. 8) Real-time updates: WebSocket.
