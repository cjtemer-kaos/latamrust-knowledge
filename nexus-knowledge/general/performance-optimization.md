# performance-optimization

Performance optimization: 1) Profiling antes de optimizar (no premature). 2) Caching en 3 niveles (app, DB, CDN). 3) Lazy loading de recursos. 4) Pagination en listados. 5) Debounce/Throttle en UI. 6) Web Workers para CPU-intensive. 7) Service Workers para offline. 8) Image optimization (WebP, lazy load). 9) Code splitting. 10) Compression (gzip/brotli).
