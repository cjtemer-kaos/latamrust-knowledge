# owasp-top10

OWASP Top 10 2021: 1) Broken Access Control → RBAC, least privilege. 2) Cryptographic Failures → TLS 1.3, bcrypt. 3) Injection → parameterized queries. 4) Insecure Design → threat modeling. 5) Security Misconfiguration → hardening. 6) Vulnerable Components → dependency scanning. 7) Auth Failures → MFA, rate limiting. 8) Data Integrity → signed commits. 9) Logging Failures → audit trails. 10) SSRF → allowlist URLs.
