# cv-pipeline

Computer Vision pipeline: 1) Image preprocessing (resize, normalize). 2) Feature extraction (CNN, ViT). 3) Object detection (YOLO, DETR). 4) Segmentation (SAM, Mask R-CNN). 5) Classification (ResNet, EfficientNet). 6) OCR (Tesseract, PaddleOCR). 7) Face detection/recognition. 8) Video analysis (frame sampling). Tools: OpenCV, PIL, torchvision.
