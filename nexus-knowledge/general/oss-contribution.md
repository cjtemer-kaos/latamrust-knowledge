# oss-contribution

Open source contribution: 1) Start with docs/issues labeled 'good first issue'. 2) Read CONTRIBUTING.md first. 3) Fork → branch → PR. 4) Follow code style. 5) Write tests. 6) Keep PRs small and focused. 7) Respond to review feedback. 8) Be patient (maintainers are busy). 9) Sign CLA if required. 10) Build reputation over time.
