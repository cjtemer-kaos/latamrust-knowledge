# system-design

System design interview: 1) Requirements: functional + non-functional. 2) Estimation: QPS, storage, bandwidth. 3) High-level design: components + data flow. 4) Deep dive: database schema, API design, caching. 5) Scaling: horizontal vs vertical. 6) Trade-offs: always discuss alternatives. 7) Common: URL shortener, chat system, news feed, search autocomplete.
