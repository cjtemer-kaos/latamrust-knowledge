# auth-patterns

Authentication patterns: 1) JWT: stateless, expira, refresh tokens. 2) OAuth 2.0: third-party auth. 3) Session cookies: server-side state. 4) API keys: para servicios. 5) mTLS: certificados mutuos. 6) Passkeys/WebAuthn: biometric. Mejores prácticas: MFA siempre, bcrypt/argon2 para passwords, token rotation, short-lived tokens.
