# prompt-techniques

Prompt techniques: 1) Zero-shot: just the task. 2) One-shot: one example. 3) Few-shot: 3-5 examples. 4) Instruction: explicit rules. 5) Role-playing: "Eres un experto en...". 6) Delimiters: XML tags, ---, backticks. 7) Output formatting: JSON, markdown, tables. 8) Constraint: "En exactamente 3 pasos". 9) Persona: "Piensa como un senior engineer".
