# avatar-kaos-plan-mañana

PLAN AVATAR KAOS MC — PASO A PASO (para mañana):

1. **INSTALAR VRoid Studio** (Steam, gratis) → crear avatar base ninja
2. **Crear personaje en VRoid:** hood oscuro, máscara, ojos rojos, armadura púrpura
3. **Exportar como VRM 1.0** 
4. **IMPORTAR en Animaze:** Animaze → Import → seleccionar VRM
5. **Configurar face tracking:** HyprFace (AI) o Visage para webcam
6. **Configurar Spout2 output** → OBS como textura
7. **OBS:**添加Spout2 como source → listo para streaming

Animaze ya tiene TODO el pipeline. No necesita construir motor ni renderer.
Solo necesita un avatar VRM bien hecho. VRoid Studio es la herramienta correcta.
