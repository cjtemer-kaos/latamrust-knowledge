# best-practices-architecture

Arquitectura de software: 1) SOLID principles. 2) 12-Factor App. 3) Microservicios cuando sea necesario (no always). 4) Event-driven architecture para desacoplo. 5) CQRS para reads/writes separados. 6) Domain-Driven Design. 7) Repository pattern para datos. 8) Dependency injection. 9) Circuit breaker para servicios externos. 10) Strangler fig para migraciones.
