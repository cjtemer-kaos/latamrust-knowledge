# supernexus-v2-architecture

SuperNEXUS v2 es un sistema de agente IA local con 22 gemas (agentes especializados), DirectorSoberano determinístico, memoria FTS5, y 38+ herramientas MCP. Servidor API en http://localhost:9000. CLI "nexus" con 12 subcomandos. Zero dependencia de LLM para core (Director puro Python). Repo: github.com/cjtemer-kaos/supernexus-v2 (main). Distro local: D:\ias\proyectos\supernexus-v2.
