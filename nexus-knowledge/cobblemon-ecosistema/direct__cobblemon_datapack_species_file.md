# Direct: Cobblemon datapack species file

Category: Cobblemon-ecosistema
Tags: direct-learned
Created: 2026-08-20T16:39:57.346364

---

Cobblemon datapack: el archivo species (JSON) de cada Pokémon contiene TODOS sus datos no-visuales: movimientos, habilidades, formas, tamaño, evoluciones. Altura en decímetros, peso en hectogramos (dividir por 10 = metros/kg). maleRatio (0-1) = probabilidad de spawn como macho. El peso determina el daño de movimientos por peso como Heavy Slam. IMPORTANTE: /reload NO recarga datapacks de Cobblemon; hay que recargar el mundo desde el menú principal para aplicar cambios.
