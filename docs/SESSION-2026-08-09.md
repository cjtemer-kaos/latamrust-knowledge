## 1. Chat — Paradigm vs Styled Chat ✅ RESUELTO

### Problema
Paradigm sobreescribe Styled Chat con `enableCustomChatFormat=true`. El chat mostraba colores incorrectos.

### Diagnóstico
- Paradigm controla el chat, NO Styled Chat
- Su `customChatFormat` gana sobre Styled Chat
- Paradigm guarda config en SQLite + espejo JSON
- **Editar el JSON directo NO sirve** — Paradigm lo sobreescribe al reload

### Solución
1. Dashboard Paradigm → desactivar `enableCustomChatFormat` → false
2. O editar JSON directamente + ejecutar `paradigm reload chat` por RCON
3. **`paradigm reload chat`** es el comando correcto (NO `paradigm reload`, NO dashboard reload)

### Resultado
- Admin: rojo + arcoíris (Styled Chat toma control)
- Trainer: cian (Styled Chat)
- Tab: `%player:name%` (sin displayname para evitar doble rango)

### Lección
Paradigm es quien controla chat/tablist. El dashboard web es la fuente de verdad pero el JSON se reescribe al reload.

## 2. Tablist — Doble Rango ✅ RESUELTO

### Problema
Jugador "jose" aparecía con 2 veces "trainer" en el tablist.

### Causa
`%player:displayname%` mostraba prefix de LuckPerms + display name = doble rango.

### Solución
Cambiar `%player:displayname%` a `%player:name%` en `config/styledplayerlist/config.json`.

## 5. YAWP — Protección de Zonas ✅ RESUELTO

### Problema
Trainers podían romper bloques en spawn (989, 72, 1071) a pesar de flags seteados a Denied.

### Investigación
- Navegué wiki oficial: https://z0rdak.github.io/yawp-docs/
- Leí código fuente de YAWP en GitHub: https://github.com/Z0rdak/Yet-Another-World-Protector
- Analicé `Permissions.java`, `RegionCommands.java`, `CommandUtil.java`

### Causa Raíz
`op_bypass_flags = true` en `yawp-common.toml` permitía que cualquier jugador con "config permission" (OPs, UUIDs en `players_with_permission`) bypassara TODOS los flags.

### Solución
1. Cambiar `op_bypass_flags = false` via SSH en PC2
2. Agregar admins como `owners` de la región spawn:
   - kaos__mcs ✅
   - robben_ ✅
   - leftor_ ✅
   - jhonsai ❌ (no encontrado como jugador)
   - aryys ❌ (no encontrado como jugador)
   - jonymcs ❌ (no encontrado como jugador)

### Configuración Actual de Spawn
- **Dimensión**: minecraft:overworld
- **Área**: Cuboid X:181-1508, Y:-64-320, Z:435-1653
- **Flags Denied**: break-blocks, place-blocks, explosions-blocks, explosions-entities, fire-tick, invincible, item-pickup, melee-animals
- **Owners**: kaos__mcs, robben_, leftor_

### Comandos YAWP (documentados)
```bash
# Gestión de players
/yawp local <dim> <region> add player owners <player>
/yawp local <dim> <region> add player members <player>
/yawp local <dim> <region> remove player owners <player>

# Gestión de flags
/yawp flag local <dim> <region> <flag> state Denied|Allowed|Disabled
/yawp local <dim> <region> list flag
/yawp flag local <dim> <region> <flag>

# Eliminar región
/yawp local <dim> <region> delete -y
```

### Lecciones YAWP
1. **SIEMPRE buscar docs del desarrollador** antes de probar comandos al azar
2. Los comandos son `add player owners` (PLURAL, no `owner`)
3. Grupos YAWP solo son `members` y `owners` (NO son grupos de LuckPerms)
4. Estados: `[+]` = Allowed, `[x]` = Denied, `[-]` = Disabled
5. Config se lee al iniciar el server — cambios requieren restart
